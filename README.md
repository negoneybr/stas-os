# SATS OS

Um ambiente desktop web independente, com visual escuro roxo/vermelho e aplicativos básicos.

## Como testar
Abra `index.html` no navegador ou publique o repositório usando GitHub Pages ou Vercel.

## Aplicativos incluídos
- **Notas:** salva o título e o conteúdo no armazenamento local do navegador.
- **Calculadora:** operações básicas.
- **Terminal:** comandos locais de demonstração (`help`, `date`, `time`, `whoami`, `apps`, `about`, `clear`).
- **Arquivos:** painel inicial de atalhos.
- **Configurações:** opções básicas de visualização.
- **Sobre:** informações do projeto.

## Importante
SATS OS é atualmente um ambiente web que funciona dentro do navegador, não um sistema operacional que substitui o ChromeOS. O painel de arquivos ainda não acessa os arquivos reais do Chromebook. As notas ficam neste navegador/dispositivo.

## Publicar
Importe este repositório no Vercel como projeto estático ou ative GitHub Pages nas configurações do repositório.
